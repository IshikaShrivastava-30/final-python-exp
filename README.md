# Global State/Province Demographic Analyzer

A Python-based data analysis and web visualization tool built to evaluate and compare demographic trends across global states and provinces.

## Features
- **Regional Filtering:** Filter and analyze population datasets dynamically by country.
- **Key Metrics Overview:** Instant calculations for total regional population, average growth rate, and demographic density.
- **Interactive Visualizations:** Clean charts detailing population distribution, population density (people per sq. km), and urban percentage.

## Tech Stack
- **Python 3**
- **Streamlit** (Web framework)
- **Pandas & NumPy** (Data processing)
